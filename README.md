# David Simon — Academic Website

Personal academic website of David Simon, Associate Professor of Economics at the University of Connecticut and NBER Research Associate.

Built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template and hosted on GitHub Pages at [davidsimon-econ.github.io](https://davidsimon-econ.github.io/).

## Structure

- `_pages/` — site pages (home, research, teaching, CV)
- `_config.yml` — site configuration (name, bio, sidebar links)
- `files/papers/` — hosted NBER working paper PDFs
- `files/Simon_CV.pdf` — current CV
- `images/profile.jpg` — profile photo

## Updating

Edit the Markdown files in `_pages/` and push to `main` — GitHub Pages rebuilds the site automatically.
