# GitHub Website Starter

A beginner-friendly website made with HTML and CSS, ready to publish with GitHub Pages.

## Files

- `index.html` — the page content
- `styles.css` — colors, spacing, and layout
- `README.md` — project instructions

## Customize the website

1. Open `index.html`.
2. Select the pencil icon to edit it.
3. Change the heading, paragraphs, and links.
4. Commit your changes.
5. Open `styles.css` to change colors, fonts, and spacing.

You can also clone the repository and edit the files in a code editor:

```bash
git clone https://github.com/DavidSimon-Econ/github-website-starter.git
cd github-website-starter
```

## Publish with GitHub Pages

1. Open this repository's **Settings**.
2. Select **Pages** under **Code and automation**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder.
5. Select **Save**.

GitHub will build the site and show its public address on the Pages settings screen. It may take a few minutes after the first deployment.

Expected site address:

```text
https://davidsimon-econ.github.io/github-website-starter/
```
